# ForexTester
<!-- impeccable:product-schema: 1 -->
## Platform
web
## Product and audience
Manual discretionary EURUSD backtesting for the project lead. Historical M1 bid/ask execution is authoritative; higher chart timeframes are analysis views.
## Core workflow
Configure account and UTC period, explicitly load data, start a paused replay, place manual orders with chart-selected independent stops, finish and review results.
## Constraints
Dark trading terminal. Chart dominates. No automated strategies, signals, take-profit orders, broker integration or financial formula changes. Preserve durable sessions, historical fingerprints, local chart preferences and no-lookahead behavior.
